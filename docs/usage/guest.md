# Guest Guide

## Joining a Room

1. Open the guest URL shared by your host.
2. Enter your display name.
3. Click **Join**.

You are now in the session as a guest.

## Topic Tree

You see the topic tree built by the host. The currently active topic is highlighted. The tree updates in real time as the host makes changes.

## Q&A

Submit questions and vote on existing ones:

- Type your question in the composer and click **Submit**.
- Vote on questions by clicking the vote button.
- Questions are sorted by vote count.
- You can vote on multiple questions.
- Anonymous mode hides your name from other guests (host still sees your `guest_id`).

## Whiteboards

### Pen Board

If the host has created a Pen Board, you see a canvas where you can draw freehand strokes. Content is shared with all participants.

### Excalidraw Board

If the host has created an Excalidraw Board, you see the Excalidraw editor in read-only mode. You cannot edit the Excalidraw board — only the host can.

## Raise Hand

Click the **Raise Hand** button to add yourself to the queue:

- Your position in the queue is visible to you.
- The host sees the full queue and can remove you when you've had your turn.
- Raising your hand again while already in the queue has no effect.

## Cursors and Click Pings

You can see other participants' cursors moving in real time. Click pings appear as brief animations when someone clicks. These are visible to all participants in the room.

## Disconnecting

Close the browser tab or navigate away. Your session state is lost but the room continues. You can rejoin with the same guest URL.
